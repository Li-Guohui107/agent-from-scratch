# AI Agent 从零开始（01）：让大模型学会调用工具

## 1. 项目简介

传统的大语言模型主要负责理解和生成文本，但在实际开发中，我们往往希望它能够完成更具体的任务，比如计算数据、查询数据库、检索文档，甚至调用外部 API。

这就需要引入 Tool Calling（工具调用）。

本项目将从一个简单的乘法工具开始，使用 Python 和 DeepSeek API，实现一个能够自主判断是否调用工具的基础 AI Agent。

## 2. 什么是 Tool Calling？

Tool Calling 指的是开发者向大模型提供可用工具的描述，让模型根据用户的问题，决定是否需要调用某个工具，以及调用时应该传入哪些参数。

需要注意的是，大模型本身并不直接执行 Python 函数。

它负责提出工具调用请求，真正执行函数的是我们的 Python 程序。

典型流程如下：

用户提出问题 → 大模型分析需求 → 选择工具 → Python 执行函数 → 返回工具结果 → 大模型生成最终回答。

## 3. 项目功能

当前版本支持：

- 通过命令行与大模型交互。
- 让大模型识别乘法计算任务。
- 自动调用 `multiply()` 函数完成计算。
- 将工具执行结果返回给大模型。
- 输出自然语言回答。
- 通过 `exit` 命令退出程序。

## 4. 环境准备

建议使用 Python 3.10 或更新版本。

首先，在项目根目录安装依赖：

```bash
python -m pip install -r requirements.txt
```

然后配置 DeepSeek API Key。

Windows PowerShell：

```powershell
$env:DEEPSEEK_API_KEY="your_api_key"
```

Linux/macOS：

```bash
export DEEPSEEK_API_KEY="your_api_key"
```

API Key 请通过 DeepSeek 开放平台获取。不要将真实密钥上传到公开仓库。

## 5. 运行项目

在仓库根目录执行：

```bash
python tutorials/01_tool_calling/main.py
```

输入示例：

```text
你：125乘以8等于多少？
```

可能的输出：

```text
[Tool] multiply: {'a': 125, 'b': 8} -> 1000

Agent：125乘以8等于1000。
```

实际输出会根据模型响应有所变化，模型不一定每次都调用工具。

## 6. 核心代码解析

**第一步：定义 Python 工具。**

`multiply()` 是普通的 Python 函数，接收两个数字并返回乘积。

**第二步：向大模型注册工具。**

通过 `tools` 参数向模型提供工具名称、功能描述和参数结构。

**第三步：处理工具调用请求。**

当模型返回 `tool_calls` 时，程序读取函数名称和参数，并执行对应的 Python 函数。

**第四步：将执行结果返回大模型。**

程序使用 `role="tool"` 将执行结果加入对话消息，再请求模型生成最终回答。

这一过程就是最基础的 Agent 工具执行循环。

## 7. 本期总结

通过这个简单项目，我们已经实现了一个能够使用 Python 工具的大模型助手。

它的核心不是让大模型写出计算结果，而是让大模型决定何时使用工具，并由程序执行实际操作。

当然，这还只是一个入门示例。在真正的工程开发中，还需要考虑参数校验、异常处理、调用次数限制和工具安全性等问题。
