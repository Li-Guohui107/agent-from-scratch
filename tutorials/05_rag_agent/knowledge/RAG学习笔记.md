# RAG 学习笔记

RAG 的英文全称是 Retrieval-Augmented Generation，中文通常译为检索增强生成。
本课程先把文档切成多个片段，再用 Embedding 模型将片段转换成向量，将向量和原文一起保存在 Qdrant 中。
用户提问时，使用同一个 Embedding 模型把问题转换成向量，检索语义相近的片段，再交给大语言模型组织回答。

Embedding 负责把文本映射为数值向量；Qdrant 负责保存和检索向量；DeepSeek 负责阅读检索到的资料并生成回答。
文档和问题必须使用相同的向量模型。更换模型后，即使维度没有变化，也应重新建立索引。
Top K 表示最多取回多少个片段，相似度阈值控制是否保留某个检索结果。相似度高不等于资料一定能回答问题。

本课用固定的检索再生成工作流实现知识库助手。向量化和检索不等于训练或微调大语言模型。
